
### 🪴 Dataset

- Fictional financial data for a simulated 5-department retail company , covering December 2025.
- This data was self-designed, with AI assistance used to generate realistic looking sample figures and variance narratives, so it doesn't represent any real company, and carries no commercial meaning
- It exists purely to give the rest of this project (SQL, Power BI, Langflow) something realistic to work with.
<br>

**🌱 Files**
| File | Description |
|---|---|
| `actuals.csv` | Actual amounts, by account, department, and month |
| `budget.csv` | Budgeted amounts, by account, department, and month |
| `chart_of_accounts.csv` | Account code → category mapping |
| `dept_id.csv` | Department code → name lookup |
