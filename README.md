**Actual vs. Budget Variance Analysis with AI-Generated Commentary**

An end-to-end FP&A project that simulates a monthly budget-vs-actual variance analysis for a multi-department retail company, combining a relational database, an interactive BI dashboard, and an AI-powered commentary pipeline. The dataset was self-designed, with AI assistance used to generate realistic sample data.

🪴 **Stack:** MySQL → Power BI → Langflow (DeepInfra: DeepSeek-V3)

---

### 1. What this project does

🌱 Every month, an FP&A team prepares the report and answer questions for management:

- **What happened?** Actual vs. Budget,for overall and by each dept.
- **Why did it happen?** The drivers behind each variance.
- **So what?** AI agent generates a English narraw down the summary.

🌱 What's the each tools for?
- **MySQL** stores actuals, budget, chart of accounts, and department-level variance explanations (as if exported from an ERP system).
- **Power BI** turns that data into an interactive P&L, variance waterfall charts, and department-level dashboards — including a custom.
- **Langflow + LLM** reads the verified numbers and ERP variance notes, and writes a management-ready narrative summary back into the database, which is then displayed inside each Power BI page.

### 3. Key design decisions
🌱 **GA cost allocation basis: Gross Profit share, not Revenue**: Rather than allocating G&A costs by revenue share (the more common default), this project allocates by each department’s share of total company gross profit. This better reflects each department’s actual contribution to profitability before overhead, rather than just its sales volume — a higher-margin department contributing less revenue but more gross profit carries a fairer share of shared costs.

🌱 **Overview page excludes GA allocation but department pages include it**: The overview page uses non-allocated actual/budget measures. Department pages use a separate “Incl GA” measure variant. This avoids double-counting: since GA costs are redistributed into department totals, summing department-level “Incl GA” figures would overstate the company total.

🌱 **Budget generation**: An early approach that generated budget figures by adding random noise to actuals occasionally produced negative Operating Profit in the budget, which is not realistic for a functioning retail business. Budgets were instead generated by targeting realistic category-level margins (benchmarked against public Ulta Beauty margin ranges), then deriving budgeted revenue/cost lines from those targets.
